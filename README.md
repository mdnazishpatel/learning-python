# 🐍 My Python Learning Journey

Welcome to my Python learning journey!

I recently started learning Python and decided that instead of only watching tutorials, I want to **learn by experimenting, building small things, breaking them, fixing them, and sharing what I learn along the way.**

This repository is where I'm documenting that journey.

## 🎯 Why Python?

I'm learning Python because I want to explore more than just web development.

I'm interested in **AI, data, automation, and software engineering**, and Python sits at the intersection of many of these areas.

My goal isn't to learn everything at once. I want to build a strong foundation and gradually move toward more practical and interesting projects.

## 📚 What I'm Learning

So far, I've been exploring:

* 🐍 Python fundamentals
* 📊 Pandas
* 📈 Matplotlib
* 📅 datetime
* 📁 os and other built-in modules
* 💾 Working with CSV files
* 🔄 Working with and processing data
* 📉 Data visualization

And this is just the beginning.

## 🛠️ Learning by Building

One thing I've realized already is that Python becomes much more interesting when you actually **build something with what you're learning.**

For example, while exploring Python libraries, I built a small weather-data project that:

**Weather Data → Pandas → Table → Matplotlib → Chart → CSV**

It started as a simple experiment, but seeing the data transform into something visual made me realize how much can be done with a few Python libraries.

## 📈 My Approach

I'm trying to follow a simple rule:

> **Don't just learn it. Build with it.**

Every new concept I learn, I try to use it in a small project or experiment.

Some projects might be simple. Some might fail. Some might be completely useless.

That's okay.

The goal of this repository is to **document the process, not pretend I already know everything.**
